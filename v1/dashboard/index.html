    Settings

    Security

    Vault PIN Not set — value reveals are unprotected
    Auto-lock after Server session expiry, and the same timeout re-locks the macOS app's Touch ID gate on inactivity
    Export password Checking… Separate from the Vault PIN — required for whole-database export, with no bypass for an unlocked session or agent token. Recommended.
    Machine lock Checking… Binds the master key to this machine's hardware/OS identity — a copied store/ + .credmgr/ refuses to decrypt anywhere else, even with raw `age`. Off by default; not reversible from any machine except this one.

    Agent Access

    MCP / agent token Checking… Gates `credmgr daemon` / MCP clients — takes effect the next time that process starts. This dashboard itself is always local-only and never needs it.
