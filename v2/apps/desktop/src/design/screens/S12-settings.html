{{machineLockTitle}}
The passphrase file is sealed with a device key kept on this Mac, outside the vault folder, and the root key and every project key are replaced. A copy of the vault folder made from now on (a synced folder, a copied directory, a USB disk) then does not open on another computer with the passphrase alone.
Copies made before now still open with the passphrase, and still show what they held then. Nothing written after this is readable in them.
If you replace this Mac, or the key file is lost, the passphrase will not open the vault there. Open it with your recovery code instead ("Forgot passphrase? Use recovery code" on the Lock screen); that also locks it to the new Mac. Another Mac sharing this vault folder needs the recovery code too. Turning this on gives you a new recovery code: the one you type below stops working. You are shown the new one and asked to type it back before anything changes.
The device key is kept out of Time Machine, so a Time Machine backup of the vault folder opens elsewhere only with the recovery code of its day. This does not protect a stolen or unlocked Mac, a whole-disk image or Migration Assistant (they carry the device key with the folder), or CredMgr backups (while the lock is on they are kept outside the vault folder, in CredMgr's state folder; they open with their backup passphrase and the vault passphrase). The device key is a file your user account can read, not a key sealed in the Secure Enclave.
