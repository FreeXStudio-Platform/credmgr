credmgr cannot reach its broker
The broker (credmgrd) is not running, or its socket is not where this app looks for it. Run credmgrd in a terminal, or let launchd keep it running (see the install guide, RELEASE.md section 3), then retry. If you started the app from a terminal by running its executable, quit it and open the app the usual way (the Applications folder, or open CredMgr.app): the bare executable has no link to the broker. Nothing from your last session is shown here.
Start the broker at login writes a launchd agent for your user only (never root) that starts credmgrd now and every time you log in. Turn it off in Settings, Security.
