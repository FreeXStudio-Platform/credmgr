## E. Suggestions
1. Keep the extras pack data-only. Never put code in it.
2. The shared code is a dictionary word; PBKDF2 slows guessing but cannot stop it. This is acceptable only because the extras are cosmetic. To rotate the code, re-seal the pack and ship a new build; installs that already opened the pack keep it.
3. Give the repo's secret scanner an allow-line for `extrasBlob()` (base64 ciphertext, ~650 characters): entropy rules will flag it.
4. Add `credmgr_keys` to `PRIVACY.md` §2.1 (it is missing from the table today) or confirm the app stores it inside `credmgr_prefs`.
5. Ask the app team to add one e2e test: enter the code, restart, extras still open, no network request.
